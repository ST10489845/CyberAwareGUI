# 🛡️ CYBERAWARE - Cybersecurity Awareness Chatbot


A WPF desktop application that educates users about cybersecurity through an interactive chatbot.

## Features

- ✅ Modern WPF GUI with dark theme
- ✅ Voice greeting with custom WAV file
- ✅ 10+ cybersecurity topics (passwords, phishing, privacy, scams, etc.)
- ✅ Random responses for natural conversation
- ✅ Follow-up question handling ("another tip", "tell me more")
- ✅ Memory (remembers user name and interests)
- ✅ Sentiment detection (worried, confused, curious, etc.)
- ✅ Quick topic buttons for easy access
- ✅ Typing indicator and chat bubbles

## Quick Start

1. Clone the repository
2. Open in Visual Studio 2022
3. Build (Ctrl+Shift+B)
4. Run (F5)

## Add Voice Greeting

1. Create `Audio` folder in project
2. Add your `greeting.wav` file
3. Set Build Action to "Content"

## Technologies

- .NET 8.0
